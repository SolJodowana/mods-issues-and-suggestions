## How to report

- **Bug:** Issues → New issue → *Bug report*
- **Feature idea:** Issues → New issue → *Suggestion*
- **Questions and casual ideas:** *Discussions* tab

## Before reporting a bug

- Include the mod version, Minecraft version, loader, and Iron's Spells 'n Spellbooks version.
- Attach a log or crash report (a link from [mclo.gs](https://mclo.gs) works best).
- Check that a similar issue doesn't already exist.
